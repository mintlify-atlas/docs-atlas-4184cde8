SickoMenu is an open-source utility mod for Among Us on Windows, distributed as a DLL that loads either via a DLL injector or automatically as a version proxy. It adds an in-game ImGui overlay with over a hundred features spanning ESP, a live radar, a movement replay system, player management, sabotage controls, task automation, and deep host-side lobby administration — all designed for private lobbies, educational exploration of game mechanics, and reverse-engineering research.

## Quick start

<Steps>
  <Step title="Download the latest release">
    Grab the correct ZIP for your platform from the [GitHub releases page](https://github.com/g0aty/SickoMenu/releases/latest).
    - **Steam / itch.io** → `Release_x86_SteamItch.zip`
    - **Epic / Microsoft Store / Xbox** → `Release_x64_EpicXboxMS.zip`
  </Step>
  <Step title="Load the DLL">
    **Recommended (no injector needed):** Place `version.dll` in your Among Us game directory — the folder that contains `Among Us.exe`.

    **Alternative:** Inject `SickoMenu.dll` with any DLL injector after launching the game.
  </Step>
  <Step title="Launch Among Us">
    Start the game normally through your platform launcher. A SickoMenu watermark appears on the main menu when the mod is active.
  </Step>
  <Step title="Open the menu">
    Press `DELETE` to toggle the SickoMenu overlay. All tabs and features are immediately accessible from the in-game window.
  </Step>
</Steps>

  SickoMenu is intended **exclusively for educational purposes and private lobbies with consenting players**. Using it in public matches violates Innersloth's Terms of Service and may result in a permanent ban. See the [Disclaimer](/reference/disclaimer) for the full ethical use protocol.
</Warning>
